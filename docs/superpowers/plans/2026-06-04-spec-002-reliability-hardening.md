**Goal:** Drive SPEC-002 ("Reliability Hardening from Grade Followups") to `satisfied`, closing 9 operational gaps and lifting `production_readiness` dim from 0.825 → ≥ 0.90.

**Architecture:** SPEC-level orchestration plan over the loop methodology. Each FEAT under SPEC-002 ships through the standard loop pipeline (decompose → triage → slice → build → grade → done). - [ ] **Step 2: Compute mean production_readiness across those slice grades**

For each grade file produced under SPEC-002, extract the `scores.production_readiness` value from frontmatter. Compute the mean. Use this script (paste into terminal — single inline node invocation):

```bash
node -e "
const fs = require('node:fs');
const path = require('node:path');
const grades = fs.readdirSync('.claude/artifacts/loop/grades')
  .filter(f => f.endsWith('-grade.md'));
const sliceIds = process.argv.slice(1);  // pass slice IDs as args
const scores = [];
for (const f of grades) {
  const body = fs.readFileSync(path.join('.claude/artifacts/loop/grades', f), 'utf8');
  const sliceMatch = body.match(/^slice:\s*(\S+)/m);
  if (!sliceMatch || !sliceIds.includes(sliceMatch[1])) continue;
  const scoreMatch = body.match(/production_readiness:\s*([0-9.]+)/);
  if (scoreMatch) scores.push(parseFloat(scoreMatch[1]));
}
console.log({ count: scores.length, mean: scores.reduce((a, b) => a + b, 0) / scores.length });
" <SLICE-A1> <SLICE-A2> <SLICE-B1> <SLICE-C1>
```

Replace the trailing `<SLICE-XX>` args with the actual slice IDs from step 1.
