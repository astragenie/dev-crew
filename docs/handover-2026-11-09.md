## How to run the loop

1. `/devcrew:start FEAT-NNN` (or no args for highest-priority triaged). It rotates `currentRun` and returns a `dispatchInstruction`.
2. Dispatch the builder it names (`crew:fullstack-dev` etc.), then reviewers A (`crew:typescript-reviewer`) and B (`crew:reviewer`) in parallel, then `crew:verifier`. Each writes its artifact with `dist/crew.js write-review-result` / `write-validation-result`.
3. Close: `CLAUDE_PLUGIN_ROOT="$PWD" bun dist/loop.js slice close --repo "$PWD" --id SLICE-NN --grade-yaml <file>`. The grade YAML must be wrapped in `---` delimiters.
4. Regenerate `loop-snapshot.md` (`dist/loop.js snapshot-memory`) and the README metrics band (`generate-metrics-band.mts --write`) before committing a close.
5. Push `main` directly (sole-operator repo; no PR flow yet). CI triggers on `main` pushes only; test a branch with `gh workflow run test --ref <branch>`.

## Known bugs and sharp edges

- `slice close --force-close` ignores `--keep-feature-open` and rolls the parent FEAT to `done/`. Needed whenever FEAT-level ACs belong to sibling slices. Restore by hand (`mv` back, `status: in-progress`, fix the synthesis/handoff "feature file (done)" line). Needs its own FEAT.
- `dist/loop.js` run outside Claude Code needs `CLAUDE_PLUGIN_ROOT` set or templates resolve against the wrong root and the slice half-closes.
- The install still writes the `runner:start` CLAUDE.md marker (rename to `devcrew:start` lands with FEAT-006 cutover).
- `validate-syntheses` (gate 33, advisory) flags "Grade missing" when a synthesis is written before the grade; backfill from the grade file.
- Bun 1.3.14: `mock.module` is process-wide in serial runs and ignores a restore whose factory returns the original namespace object (see `cost-scan-cursor-honesty-guard.test.mts`).
- Never `git stash` on the shared checkout while builder agents are running; use a worktree lane.
- Six root test suites touching git worktrees are quarantined (non-blocking) on CI; see `docs/ci-gates.md` § Job structure.

## CI specifics

- `fast-gate` calls the **vendored** `.github/workflows/reusable-plugin-ci.yml` (copied from private `astragenie/common@v1`; a public repo cannot call it there). Sync by hand if `common` changes.
- Every job installs the Bun version in `.bun-version` into `$RUNNER_TEMP` (runner image drifts; `build-dist --check` byte-compares `dist/`).
- Runners are org-level (`astragenie-runner-runner-gcp-c-*`, label `self-hosted`).
