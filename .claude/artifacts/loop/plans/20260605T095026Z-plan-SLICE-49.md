## Open questions

1. No builder_complete trajectory step exists. Trajectory only records slice_start and
   slice_complete. Builder evidence must be injected via opts at call time, not read
   from the trajectory file.

2. Injection interface: completeSlice(repoPath, sliceId, opts) already accepts an opts
   bag. opts.builderEvidence?: BuilderEvidence is the minimal extension.

3. When evidence is absent: opts.builderEvidence is undefined/null. updated_confidence
   is null in the return. Existing tests do not assert this field -- backward-compatible.

4. Extend computeConfidence or add sibling helper? A separate
   computePostBuilderConfidence(evidence: BuilderEvidence) helper in
   confidence-signal.mts is correct: single responsibility, no change to the existing
   API (AC-3/AC-4 preserved), avoids touching start-slice.mts.

5. Failure signal definition: BuilderEvidence.status is "pass" | "fail" | "partial"
   plus optional failures: string[]. fail+test-fail or fail+build-fail => red.
   partial or fail without specific failures => yellow. pass => green.

## Proposed approach

### Key decisions

- Evidence source: opts injection (opts.builderEvidence), not trajectory-read, because
  no builder_complete step type is written today.
- New helper: computePostBuilderConfidence(evidence: BuilderEvidence): ConfidenceResult
  added to src/scripts/lib/confidence-signal.mts. Pure function, no IO, exported.
- Caller site: completeSlice reads opts.builderEvidence, calls helper when present,
  attaches updated_confidence and updated_confidence_reason to the return.
- start-slice.mts is untouched -- AC-3 is structurally enforced.

### Step 1 -- Extend confidence-signal.mts

Add to src/scripts/lib/confidence-signal.mts (currently 67 lines, stays under 400-line cap):

    export interface BuilderEvidence {
      status: "pass" | "fail" | "partial";
      failures?: string[];  // e.g. ["test-fail", "build-fail"]
    }

    export function computePostBuilderConfidence(
      evidence: BuilderEvidence
    ): ConfidenceResult {
      if (evidence.status === "pass") {
        return { confidence: "green", reason: "builder reported all checks passed" };
      }
      const failures = evidence.failures ?? [];
      const hasHardFail = failures.some(
        (f) => f === "test-fail" || f === "build-fail"
      );
      if (hasHardFail) {
        return {
          confidence: "red",
          reason: "builder reported hard failures: " + failures.join(", ")
        };
      }
      return {
        confidence: "yellow",
        reason: evidence.status === "partial"
          ? "builder reported partial completion"
          : "builder reported failure (no specific kind recorded)"
      };
    }
