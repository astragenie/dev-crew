### Step 2 — Create read-only helper module (AC-7)

**File:** `src/scripts/lib/contracts-artifact.mts` (NEW)

**Change shape:** Two pure functions, no dispatch logic, no Edit/Write — read-only by design (the slice file calls this out explicitly).

```ts
import path from "node:path";
import { pathExists } from "./paths.mjs";

const CONTRACTS_DIR = ".claude/artifacts/crew/designs";

export function getContractsPath(repoPath: string, featureId: string): string {
  return path.join(repoPath, CONTRACTS_DIR, `${featureId}-contracts.md`);
}

export async function contractsArtifactExists(
  repoPath: string,
  featureId: string
): Promise<boolean> {
  return pathExists(getContractsPath(repoPath, featureId));
}
```

Reuses `pathExists` from `src/scripts/lib/paths.mts` (already imported across the codebase). The constant `CONTRACTS_DIR` is hardcoded to `.claude/artifacts/crew/designs` because that path is owned by hero-crew's artifact convention, not by loop config — exposing it in `paths.mts::PATH_DEFAULTS` would falsely imply it is loop-tunable. Builder should NOT add a config key for it.
