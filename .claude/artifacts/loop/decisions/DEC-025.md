# DEC-025: Use `Record<string, any>` not `Record<string, unknown>` for opaque property bags

## Context

Test helper objects and frontmatter bags are heterogeneous by design; `unknown` would require casts at every access point. `Record<string, any>` is the approved pattern per local code conventions and was already used throughout src/scripts.
