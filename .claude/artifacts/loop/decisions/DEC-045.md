# DEC-045: Cost-report honesty guards live in one shared helper applied to every write path

## Context

Zero sessions scanned, a window wider than maxWindowHours without --allow-wide-window, or a duplicate run_id with identical totals each mean the report cannot be honest about what it measured. The three checks plus run_id resolution were extracted into cost-report-guard.mts's evaluateCostReportGuard and wired into both maybeEmitCostReport (interactive) and costSliceHandler (autonomous loop) rather than duplicated, because the first implementation shipped on only one of the two paths and nothing caught it until live evidence did.
