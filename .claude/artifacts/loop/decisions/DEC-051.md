# DEC-051: Marker file signals fanout dispatch, not heuristic detection

## Context

Counting reviewer artifacts to infer "fanout ran" is fragile — serial dispatch can produce 2 artifacts, fanout produces 2 reviewer artifacts + 1 validator. Lifetime-unique slice IDs + explicit marker is robust + auditable. The marker also lets future tooling distinguish "fanout dispatched but failed" from "fanout never invoked".
