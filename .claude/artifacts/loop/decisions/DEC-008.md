# DEC-008: isWorkingTreeClean takes no stagedOnly parameter

## Context

The `stagedOnly` branch of `isWorkingTreeClean` was dead code — both success and catch paths returned `true` unconditionally, making the `git diff --cached --quiet` call a no-op. The real staged-only clean-check is the `git diff --cached --stat` re-check that follows unconditionally. Removing `stagedOnly` from the function signature makes the two-stage flow readable: full-tree mode does porcelain check + git add -u; both modes then do the staged re-check.
