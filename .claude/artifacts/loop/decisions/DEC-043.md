# DEC-043: rulesBlock wiring added to buildTokens extras interface

## Context

Template `{{rulesBlock}}` token was added but `buildTokens` did not return it, causing `renderTemplate` to leave the literal `{{rulesBlock}}` in rendered output. Fixed by extending the `extras` parameter with `rulesBlock?: string` and returning it (defaulting to `""`). Alternative of a separate token builder was rejected — `buildTokens` is the canonical token assembly point.


## Decision

The decision in declarative voice. "We will …"

## Consequences

### Positive

- `{{rulesBlock}}` token is now properly substituted in rendered templates
- Callers must pass `rulesBlock` via `extras` to populate it (wiring from `loadRules` → `buildRulesBlock` → `buildTokens` is a follow-up task)
- Pattern established: all template tokens must be threaded through `buildTokens` extras
