# DEC-043: Review/validation gates require explicit terminal verdicts; ladder entries are slots counted by distinct approving keys

## Context

Scaffold/in-progress writes used to stamp review_passed with no verdict, and one reviewResult slot made reject-then-approve green (Codex #20/#21). `--decision` is now required on terminal writes; scaffolds register no verdict. `required` snapshots reviewers.ladder at run-brief time but is interpreted as a slot count because ladder labels (A/B) never match the role-name keys reviewers actually write; the fanout prompt now hands each reviewer its slot key so two stock reviewers cannot collapse onto one key.
