# DEC-040: ENOENT returns empty string instead of throwing

## Context

Repos without a `skills/` directory are the common case for new installs. Throwing would block `installLoop()` for all pre-existing repos on upgrade, which is unacceptable. Returning `""` means the `{{skillActivationBlock}}` token renders as empty — safe no-op.
