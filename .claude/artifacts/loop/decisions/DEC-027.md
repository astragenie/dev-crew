# DEC-027: Disable exactOptionalPropertyTypes in tsconfig.test.json

## Context

The test config overrides `strictNullChecks: false` for pragmatic reasons (legacy tests written before strict null checks). TypeScript requires strictNullChecks for exactOptionalPropertyTypes to be enforceable. Rather than enable strictNullChecks in test config (which would break many tests), override the flag to false in test-only config.
