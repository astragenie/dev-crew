# DEC-029: Stay at schemaVersion:1 for additive optional fields

## Context

When FEAT-075 added `roles.<name>.skills` to the preset schema, the change was additive and optional. Bumping schemaVersion to 2 would have forced every consumer (and every shipped preset file) to update for no behavior change. Per Phase 1 design's backward-compat rule: additive optional fields keep v1.
