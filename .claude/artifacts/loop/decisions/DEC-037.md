# DEC-037: HTML-comment clause-id convention

## Context

HTML comments don't render in Markdown viewers, so prose stays clean. Easy to grep (`grep -n "<!-- clause:"`), easy to extract (regex). Stable: H2 text can be lightly edited without breaking the id. Kebab-case derived from H2 title for human readability.


## Decision

The decision in declarative voice. "We will …"

## Consequences

### Positive

- positive: zero visual change to CLAUDE.md when rendered
- positive: trivial machine extraction via 1-line regex
- negative: rename of an existing clause silently breaks all outstanding `declined_per` citations; no rename-aware tooling yet
- negative: requires care to keep id and H2 wording aligned over time
