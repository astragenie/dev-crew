# DEC-042: Guard empty-string patterns in patternSubsumed rather than allowlist

## Context

`patternSubsumed` used `p1.includes(p2)` for overlap detection. `String.includes("")` returns true for any input so a rule with `globs: [""]` would match every inScopeGlob. Added `if (!p1 || !p2) return false` guard as the minimal fix rather than switching to an explicit allowlist. Guard is the correct semantic: empty patterns should not subsume anything.
