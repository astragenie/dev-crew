# DEC-009: Remote import half of FEAT-007 rejected

## Context

Fetching rule docs from GitHub URLs at install time introduces a network dependency, has no integrity check (no hash pinning), suffers from silent staleness when the upstream branch changes, and provides no safety advantage over committing docs locally. The `@include` mechanism in CLAUDE.md already handles static context injection. Risk/benefit ratio is unfavorable.

## Consequences

### Positive

- Feature ships as config-only with no network calls — safe, fast, deterministic
- Teams wanting shared rule sets must commit files locally or use git submodules — explicit, auditable
- If demand for remote import grows, it can be added as FEAT-007-B with explicit version pinning and integrity verification
