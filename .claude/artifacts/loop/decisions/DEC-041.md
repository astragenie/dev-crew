# DEC-041: Only `manual` and `glob` triggers emit activation lines; `always_on` and `model_decision` are silently filtered

## Context

`always_on` skills require no agent instruction — they're unconditionally loaded. `model_decision` is at the model's discretion by definition. Adding them to the activation block would be redundant noise. Only conditional triggers need explicit guidance.
