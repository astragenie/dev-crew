# DEC-048: Shipped hook and CLI entry points are self-contained dist/ bundles, not auto-installed dependencies

## Context

Claude Code auto-installs plugin-root dependencies for marketplace installs, but devcrew is ineligible (root bun.lock declares workspaces, crew/ depends on a git URL, @astragenie/* needs registry auth at install time) and crew/'s own package.json is never installed. Bundling via Bun.build (target bun, external @opentelemetry/* and @aws-sdk/*) needs no network, no auth, and no install step; dist/ is committed and gate 21 (`build-dist.mts --check`, Bun version pinned by .bun-version) keeps it fresh.
