# DEC-030: Extend Variant union to include RoleName rather than add a separate --role flag

## Context

Adding `--role pm` as a separate CLI flag would have created two parallel surfaces (`--variant fe|be|single` and `--role pm|researcher|...`) for what is conceptually one selection. Widening the existing `--variant` to accept role names keeps the API single-axis. `pickBlock` branches on `isRoleVariant` early; behavior stays clear.
