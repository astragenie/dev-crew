# Release v0.34.0 — glob-scoped rule auto-attach

## What shipped

**FEAT-082 SLICE-86** — Glob-scoped rule auto-attachment library.

- `loadRules(rulesDir)` reads `*.md` rule files, parses frontmatter, returns `Rule[]`
- `buildRulesBlock(rules, inScopeGlobs)` filters and renders matching rules into MASTER_PROMPT
- `{{rulesBlock}}` template token wired into `buildTokens` and `templates/master-prompt.md`
- 1091 tests pass; lint/typecheck/format/manifests clean

## Bug fixes (caught in review)

- **DEC-042** — Empty-string glob guard: `patternSubsumed` now returns `false` when either pattern is empty, preventing `"text".includes("")` false positives
- **DEC-043** — `buildTokens` now returns `rulesBlock` so `{{rulesBlock}}` renders correctly in templates

## Not yet wired

`rulesDir` → `loop.json` config schema integration and the actual `loadRules` call from `buildTokens` are deferred to a follow-up slice. The library functions are ready; the install-time wiring is next.

## Test count delta

1065 (v0.33.0 baseline) → 1091 (+26 new tests across `rule-loader.test.mts` and `loop-installer-tokens.test.mts`)
