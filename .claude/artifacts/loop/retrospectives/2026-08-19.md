### What went wrong

  24 remote commits (incl. the v0.67.0 enforcement hooks) silently missed
  the import and were only discovered during the archive-banner push.
  Root cause: no fetch-and-compare before tagging. The repo memory already
  carried this exact lesson from a prior release; it was not consulted at
  tagging time.
- devcrew.json carried stale pre-unification stack commands
  (`node ./scripts/validate-*.mjs`) from the P0 seed; the phase gate FAILed
  on them at program close. Config seeded early in a program needs re-audit
  when the tree layout changes under it.
- Two suites needed serial mode on the Linux CI runner (bun#5090-class
  starvation, roaming exact-60s hangs). Parallel remains local-only until
  the upstream scheduler fix lands.

### What to do differently
- Any baseline/import tag: `git fetch && git status -sb` first, always.
- Marker/token migration tools: enumerate ALL legacy namespaces before the
  first apply, and dry-run against the full real estate, not fixtures.
- When a gate self-references a cutover (marketplace-sync demanding the
  swap it guards), plan the swap and the gate flip as one paired change.
