## Description

Post-audit residuals: declare skills in plugin.json, shrink the shipped cache, purge stale skill ids and FEAT-id refs from prompts

Source: smoke baseline rows "Skill discovery undeclared" and "Plugin cache size 44 MB" (no FEAT closes them — reviewer coverage table); audit #30 (crew/docs/routing-table.yaml:185,306,309 cite microsoft-docs:* and context7.get-library-docs, skills that do not exist) and #38 (12 distinct FEAT ids + 4 backlog paths hard-coded in agents/). Deferred: not in waves 1-5; schedule after FEAT-032 sign-off unless PM scores it into wave 3. Depends on: FEAT-033 (hooks path settled first so plugin.json edits do not collide).

Problem: .claude-plugin/plugin.json has no `skills` key while 79 SKILL.md files sit at depth 2-5 under skills/ — auto-discovery is documented only for skills/<name>/SKILL.md, so most skills may be invisible to consumers (unverified live; verify first with `claude plugin validate --strict` and a `--plugin-dir` session listing skills). The git-checkout cache ships crew/tests (179 files) and src/tests (336) — 44 MB per version. routing-table.yaml and six agent prompts cite skills and FEAT ids that no longer exist.

Deliverable:
- Verify skill discovery live (record in docs/audits/2026-11-05/README.md); if nested skills are not discovered, add an explicit `skills` array to plugin.json generated by a small script (src/scripts/render-plugin-skills.mts) and a validator rule that the array matches the tree.
- Cache size: evaluate what the marketplace cache actually clones (git checkout of the repo); if tests cannot be excluded at clone time, record the decision (accept size) in docs/memory.md and drop the item; otherwise move test trees as decided.
- routing-table.yaml: remove or remap the nonexistent skill ids; validate-routing-table.mts --coverage-only must flag them going forward (add fixture).
- agents/*.md: replace hard-coded FEAT ids and backlog paths with role-relative wording; add a validate-agent-refs rule "no FEAT-NNN literal in agents/" with an allowlist for the 3rdparty dir.

Acceptance criteria:
- Given a `--plugin-dir` session with the staged copy, when skills are listed, then every skills/**/SKILL.md is available (or the plugin.json `skills` array makes it so) and the result is recorded.
- Given routing-table.yaml, when validate-routing-table.mts --coverage-only runs, then exit 0 and a fixture citing a nonexistent skill id exits 1.
- Given agents/ (excluding 3rdparty), when validate-agent-refs runs, then no `FEAT-\d+` literal remains.
- docs/memory.md records the cache-size decision with the measured clone size.

Scope: .claude-plugin/plugin.json, src/scripts/render-plugin-skills.mts (new), crew/docs/routing-table.yaml, crew/scripts/validate-routing-table.mts, src/scripts/validate-agent-refs.mts, agents/*.md (text only), docs/memory.md, docs/audits/2026-11-05/README.md.
