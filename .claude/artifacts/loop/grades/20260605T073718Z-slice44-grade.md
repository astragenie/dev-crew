## Decisions

### DEC-010: ORCHESTRATE_SLICE_MIN_CREW_VERSION separate from MIN_CREW_VERSION

**Rationale**: Bumping MIN_CREW_VERSION to 0.10.0 would break install for all users on crew < 0.10.0; orchestrate-slice falls back gracefully, so it only needs its own soft gate constant.

**Consequences**:
- Users on crew 0.3.6–0.9.x can still install loop; they get the legacy crew:builder dispatch path.
- ORCHESTRATE_SLICE_MIN_CREW_VERSION = "0.10.0" is the sole gate for the new dispatch path.
