## Lessons

- **Deferred tool gap**: granting a tool in agent frontmatter is necessary but not sufficient when the tool is deferred. Agent dispatches need explicit ToolSearch invocation BEFORE use. Without ToolSearch, the tool appears absent from the active surface even though frontmatter permits it. Worth a global agent-authoring checklist entry.
- **Possible retroactive explanation for crew:lead specialist-pause** (FEAT-191): the same deferred-Agent gap may have caused N% of lead's narration-only returns. Not the full story but worth investigation upstream. Documented in CHANGELOG.
- Validation-driven discovery is the right pattern: shipped FEAT-195, validated via real dispatch on FEAT-085, surfaced the ToolSearch gap, shipped FEAT-196. Each step ~10 min. Two iterations beat one big design.

## Surprises

- The CLAUDE.md note added 2026-06-10 about lead/Agent was correct but ambiguous: "If ToolSearch does not show Agent, that means Agent is a base tool already loaded — invoke it directly." This advice is incomplete for the deferred case. Worth updating once we confirm the lead-pause connection.
