## Decisions

### DEC-039: Legacy crew:/loop: dispatch tokens hard-fail as of v1.1.0

**Context**: Deprecation announced at v1.0.0; operator explicitly ordered enforcement. The allowlist never contained a runner: namespace (verified historically).

**Decision**: All 12 legacy allowlist entries removed; legacySuccessors map prepends an actionable retirement message naming the devcrew successor; devcrew:release-engineer allowlisted so deployment ceremony dispatch has a reachable successor; a reachability test pins every recommended token to a passing guard verdict.

**Consequences**:
- Legacy dispatch tokens block with migration guidance; future successor-map edits cannot recommend unreachable tokens without a red test.
