## Lessons

- CI gate logic that lives inline in workflow YAML is untestable; extracting it to two small shell scripts made the fail-closed matrix (7 combinations incl. blank/garbage CODE) a unit test and let the verifier probe CRLF and real diffs locally.
- A required job must carry `if: always()` or a failed upstream job SKIPS it instead of failing it; the scripts only fail closed because the wiring already had it — verify the wiring, not just the script.

## Decisions

### DEC-041: Backlog files are CI code, not docs-only

**Rationale**: `.claude/artifacts/loop/backlog/**` feeds validate-effort-points, validate-decline-citations, validate-loop-state and validate-backlog-drift; exempting them as docs skipped all four. The docs-only exemption is now exactly ^(docs/|README\.md$|CHANGELOG\.md$).

**Consequences**:
- Backlog-only PRs run fast-gate; prompt files (agents/commands/skills) always run validators; gate fails closed on empty change detection.
