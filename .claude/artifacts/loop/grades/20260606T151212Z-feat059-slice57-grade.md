## Decisions

### DEC-021: autoMode demotes ONLY listed categories, never cost-critical halts

**Rationale**: Per-category ignoredCategories list (default `['score-trend']`) is opt-in. Cost halts (cost_alert_high, cost_regression_stop, slice-cost-ceiling) are NOT in the default ignored list — they remain halt-blocking even in autoMode. Operator can add categories explicitly but the safety default is "cost always halts."

**Consequences**:
- positive: marathon continues despite subjective score-trend warnings
- positive: real money / safety gates stay strict
- negative: operator who wants "ignore everything" must list each category — friction is intentional

### DEC-022: detectCostMode normalizes git-dir vs git-common-dir paths before comparison

**Rationale**: Git emits `--git-common-dir` and `--git-dir` in inconsistent formats (relative vs absolute) depending on env. String-equality is unreliable. `path.resolve(repoPath, ...)` normalizes both to absolute before comparing.

**Consequences**:
- positive: detectCostMode works correctly when user-home or parent dir is itself a git repo (Windows common case)
- positive: cross-platform path semantics match
- negative: pulls in node:path import inside the function (minor)
