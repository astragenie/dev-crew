## Lessons

- Workflow batch agents obey in-repo comments over dispatch context: round-2
  spawn agents left node-spawns alone because a comment cited ADR-002, which
  the plan had disposed as obsolete. When a decision supersedes in-repo
  documentation, the dispatch prompt must name the superseded artifact
  explicitly or agents will defer to it.
- Cross-agent clobber is real in shared-tree parallel edits: 4 files reverted
  mid-flight (likely a sibling's tree-wide git op). Defense that worked:
  per-file end-of-batch re-verify + final-gate grep. Prohibit git
  checkout/restore/stash in every shared-tree fan-out prompt.
- A green run can hide a silent-zero: test-shard discovered 0 files post-rename
  and CI sharding would have reported success. Discovery filters need
  count-nonzero assertions.

## Decisions

### DEC-007: All repo-script spawns run under bun; ADR-002 node-consumer path retired in dev-crew

**Rationale**: Node's strip-types resolver never maps .mjs->.mts, so the
.mjs-specifier convention is Bun-only; production hooks.json already invoked
bun. One runtime end-to-end per the unification plan §3.

**Consequences**:
- positive: suite fully green serial+parallel (1971/0), 13.2s parallel wall
- negative: plain-node execution of crew CLI unsupported from here on

## What went well

The 3-round, 219-file `node:test` -> `bun:test` migration reproduced exactly: reviewer round-tripped the suite to 1971 pass / 0 fail / 117 skip, verified test-count parity on 150 modified files, confirmed assertion-mapping fidelity by executing (not assuming) bun:test's message form, and found zero missed conversions.

## What went wrong

Cross-agent clobber hit a shared-tree parallel edit — 4 files reverted mid-flight, likely from a sibling agent's tree-wide git operation — and a round-2 batch left node-spawns alone because an in-repo comment cited an ADR the plan had already disposed as obsolete, since batch agents defer to in-repo documentation over dispatch context.

## What I would do differently next time

Name superseded artifacts explicitly in the dispatch prompt so agents don't defer to stale in-repo comments, prohibit git checkout/restore/stash in every shared-tree fan-out prompt, and add count-nonzero assertions to discovery filters so a silent-zero (test-shard finding 0 files post-rename) can't pass as a green run.
