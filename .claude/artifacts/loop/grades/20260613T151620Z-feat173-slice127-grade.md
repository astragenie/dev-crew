## Decisions

### DEC-056: _repoPath parameter kept for API documentation, all operations use child.worktreePath as cwd

**Rationale**: The `repoPath` parameter originally appeared to serve as the working directory, but all actual git/gh operations use `child.worktreePath`. Renaming to `_repoPath` signals it is documentation-only and suppresses lint warnings without removing it from the public API surface.

**Consequences**:
- Callers who pass `repoPath` see it documented correctly
- Lint is clean with no `no-unused-vars` suppression comments
