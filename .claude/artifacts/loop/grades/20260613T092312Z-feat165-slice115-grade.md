## Lessons

- Reading jsonl line-by-line with skip-on-malformed is the right approach for append-only audit logs — never fail the whole report on one corrupt line
- 4-week rolling average as baseline for delta % is intuitive for weekly cost review; median would be more robust but adds complexity not justified by the use case
- `null` / missing `skill_name` in dispatch log entries should bucket to `"(unknown)"` not throw — real-world logs have gaps
