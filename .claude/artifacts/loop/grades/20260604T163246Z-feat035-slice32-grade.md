## Decisions

### DEC-007: cost-report supports multiple --source-project flags via costProjectAliases array

**Rationale**: After a repo rename or path change, historical cost session data sits under the old slug while new data lands under the new slug. Forking a fresh stream (just changing `costProject`) loses the history. A `costProjectAliases: string[]` config key lets the cost CLI query both buckets, addit­ively. Crew's `cost-slice` CLI was confirmed (via live smoke) to accept multiple `--source-project` flags.

**Consequences**:
- positive: historical cost data remains accessible after repo renames; cost-trend signal stays continuous across migrations
- positive: zero behavior change when `costProjectAliases` is absent (back-compat preserved)
- negative: aliases are config-driven; users have to remember to add them post-rename. Future helper could auto-detect from git history.
- negative: relies on the crew CLI's additive behavior; if a future crew version changes semantics, this needs coordination.
