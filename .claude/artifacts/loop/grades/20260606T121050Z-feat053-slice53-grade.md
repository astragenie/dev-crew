## Decisions

### DEC-015: Normalize checked boxes to unchecked in derived ACs

**Rationale**: Slice scaffold represents work-to-do. If a parent FEAT author ticked an AC as done (`[x]`), the derived slice scaffold should still show `[ ]` because the slice itself starts fresh. Reviewer caught this; builder originally passed lines verbatim.

**Consequences**:
- positive: AC linter sees only `[ ]` boxes; slice represents fresh work
- positive: defensible against future spec ambiguity ("all unchecked" was the intent)
- negative: a FEAT author who deliberately wants to carry over checked state cannot — no way to preserve `[x]` through the parser

### DEC-016: Slice-level scoping deferred

**Rationale**: AC-4 deliberately scoped first-slice-gets-all behavior. Multi-slice AC scoping (frontmatter markers picking subsets) was kept out of scope — design TBD, FEAT-053 didn't pre-decide.

**Consequences**:
- positive: ships value sooner; multi-slice authors still get verbatim ACs as starting point
- negative: when FEAT splits into 3+ slices, every slice initially carries all ACs; author must trim manually
- followup: when a real multi-slice FEAT lands, capture scoping pattern empirically before designing frontmatter markers

## Surprises

- `## Acceptance criteria` heading is rarer in this repo's FEAT bodies than expected. Most loop-side FEATs use inline `AC-N:` text. Confirmed by validator: FEAT-052 had heading (4 ACs extracted); FEAT-056 had inline text (0 extracted, fallback fired).
- Reviewer flagged TDD-gate as "unverifiable" because diff was uncommitted at review time. Process gap — review ran on working tree, not commit.

## Followups

- **Specialist-pause pattern**: builder + validator + reviewer all pause mid-investigation without writing artifact. FEAT-052 covers reviewer; needs extension to all roles. Either prompt-level reminder OR CLI-side enforcement.
- **FEAT body format alignment**: standardize `## Acceptance criteria` heading + `- [ ]` lines across FEAT corpus. Retroactive migration OR extend parser to recognize inline `AC-N:` format.
- **Multi-slice AC scoping**: defer until first 3-slice FEAT lands.
