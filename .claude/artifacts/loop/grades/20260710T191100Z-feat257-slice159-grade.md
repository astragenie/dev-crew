## Lessons

- Builder reported "tsc clean" while a mid-edit LSP snapshot showed hard "Cannot find name" errors; independently re-running every gate after a fix pass (not trusting the report) is mandatory — the final tree was clean but the claim was unverifiable at report time.
- The reviewer's HIGH finding turned a remediation tool that could leave state WORSE than the bug it fixes (half-renamed slice) into one that reports partial progress on failure; for destructive multi-file ops, "report exactly what you changed before rethrow" is a hard requirement, not a nicety.
- Dropping the renumber event from grades.jsonl (rather than hand-rolling a scores-less grade line) respected the FEAT-258 all-zero-guard — non-grade events must not be shoehorned into the grade ledger; route them through the correct sole-writer (appendSliceEvent) so webhook fan-out fires.

## Surprises

- On-disk artifacts use a legacy kebab slug form (slice-147) that buildArtifactSlug's tight token (slice147) never produces; the renumber CLI needed a documented secondary match for the exact file class the real FEAT-244/247 incident hit.

## Followups

- SLICE-C (deferred) — wire a runner:start-time collision-detection check that surfaces the slice-renumber command, plus a docs/conventions/slice-id-allocation.md documenting the fetch-scan + renumber contract for future KIND_REGISTRY additions.

## What went well

Design-first (DEC-079) paid off: the builder followed Option C cleanly, reused KIND_REGISTRY via buildArtifactSlug so future artifact kinds are covered automatically, and both slices landed with real git-backed tests. The reviewer caught a genuinely important HIGH (partial-failure state) that the gates could never surface.

## What went wrong

Builder self-reported green while an intermediate edit state had hard tsc errors, forcing independent re-verification. First SLICE-B pass hand-rolled append-only ledger writes, bypassing sole-writer helpers and emitting a malformed/miscategorized event — caught in review, not by the builder's own gates.

## What I would do differently next time

Have the builder run the full gate set as the LAST action before reporting (not mid-edit), and always route append-only ledger writes through the typed sole-writer helper so a schema mismatch is a compile error, not a review finding.
