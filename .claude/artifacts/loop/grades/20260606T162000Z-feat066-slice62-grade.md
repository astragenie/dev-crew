## Lessons

- Path resolution gotcha: `new URL(import.meta.url).pathname` returns `/C:/...` on Windows (leading slash). Use `fileURLToPath` from `node:url` instead.
- `npm run build` only refreshes the source build; `npm run build:tests` is a separate target. When editing tests, always run both before iterating.
- The three-way contract pattern (registry source ↔ doc ↔ runtime emission) is a powerful template. Could be reused for: backlog frontmatter fields, slice frontmatter, decision frontmatter — anywhere a documented schema and a runtime emitter must stay in sync.
