## Decisions

### DEC-061: MIN_CREW_VERSION floor rests on reviewer/validator scaffold coverage only

**Rationale**: Released crew 0.47.0 carries the scaffold-first contract
in inspector/verifier only; builder-tier uses a different no-artifact
mechanism and aiplugin-dev's contract is merged upstream but
unreleased. The floor is honest about what it guarantees.

**Consequences**:
- Positive: install gate now guarantees the reviewer/validator pause
  protection that the SOP's self-heal claim depends on.
- Negative: a residual re-pin task remains open (next crew release)
  before the SOP manual fallback can be retired for builder-tier and
  aiplugin-dev; tracked in the upstream-request's residual row.

## What went well

## What went wrong

review rejection that better parent-side verification would have
avoided. The auto-derived slice file carried placeholder scope bullets
("bullet 1/bullet 2") — sliceFromFeature should synthesize scope from
the FEAT body instead.

before writing it into dispatch context (merged-to-main ≠ released).
