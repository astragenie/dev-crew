## Lessons

- locateSliceFile is process-cached via cache.mjs::cached(). In the existing 3-step flow each subcommand runs in its own process so the cache is harmless. In an in-process orchestrator (closeSlice), the cache returns the stale pre-move path. Fix is one bust call. The lesson: any future in-process orchestrator that calls completeSlice + downstream-lookups must invalidate this key.
- autonomous_safe gate ran cleanly BEFORE completeSlice. Side-effect testing (pendingDir.readdir + idPattern check) caught the slice-filename-with-underscores trap on the first run; small thinko but the assertion saved it. Lesson: check the on-disk filename pattern, not just the id string.
- Test fixture caught a subtle bug that production never would have: in-process orchestration breaks the per-process cache assumption. Worth keeping in mind for the upcoming triage+enrich merge.

## Surprises

- The 3-step path's cache isolation was load-bearing. Not documented anywhere; the closeSlice impl had to discover it. Worth a comment in cache.mjs.

## Followups

- Eat own dogfood: switch crew:lead's slice closure step in `commands/slice-post-builder-fanout.md` (or wherever the closure template lives) to emit `slice close --grade-yaml` for autonomous_safe slices. Saves one round-trip per slice.
- Triage+enrich merge (FEAT-189) — next.

## What went well

- Clean separation: closeSlice owns orchestration; existing completeSlice / createGradeFile / writeGrade unchanged. Back-compat trivially preserved.
- Failed tests on first run pointed straight at the cache issue. Fix was 2 lines.
- 5 distinct test surfaces: scaffold-only, lib happy, lib refuse, CLI happy, CLI refuse. No coupling between tests.

## What went wrong

- Initial assertion used `f.includes(sliceId)` against filenames that use underscores in place of hyphens. False-negative for one cycle; cost ~3 min.

## What I would do differently next time

- When testing slice-path assertions, run a one-line debug `readdir` first to see what the file is actually called. Cheaper than guessing the convention.
