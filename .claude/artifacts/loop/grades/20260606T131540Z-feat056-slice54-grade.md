## Decisions

### DEC-017: Override flag is surgical, not broad

**Rationale**: `--allow-cross-session` filters ONLY `session_drift_stop` from reasons. If cost-regression-stop fires simultaneously, walker still halts on that. Override is not "ignore all halts" — only the specific gate the operator authorized.

**Consequences**:
- positive: prevents accidental override of cost halts when operator only meant to override session affinity
- positive: composable with future per-gate override flags
- negative: operator who wants "just keep going" needs to set multiple flags; intentional friction

### DEC-018: workflow-state.json created with minimal schema when absent at slice-start

**Rationale**: First-slice scenario in a fresh repo: no workflow-state exists yet. Original implementation no-op'd, leaving the sessionId unpinned forever. Lead changed to create the file with `{ version: "1.0", currentRun: { sessionId } }` so the pin survives.

**Consequences**:
- positive: session-pin works from slice 1, not slice 2 onward
- positive: minimal schema is compatible with crew's later writes (crew merges into existing state)
- negative: introduces a write path loop did not previously own; potential for schema divergence if crew adds required fields
