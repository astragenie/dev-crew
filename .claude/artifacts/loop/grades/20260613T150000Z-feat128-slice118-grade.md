## Inference

- reliability: fail-open on all three error paths (absent file, malformed JSON, missing triggered flag); idempotent resume (no-op on double-resume); no process.exit from library functions

## Lessons

- Fail-open on state files is the right default — a partial write or corrupt file must never permanently block the walker; the operator must produce a fully valid payload with triggered: true to engage the halt
- Idempotent resume keeps the operator UX simple: running resume twice is not an error
- File-based state survives session restart, which is the key property that makes pause semantics useful for async waits
