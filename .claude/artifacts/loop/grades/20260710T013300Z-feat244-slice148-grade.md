## Lessons

- Per-entry try/catch in the sweep loop with a classified error kind (403/insufficient-scope vs 404/not-found vs other) makes "one dark repo" a recorded per-repo state instead of a whole-tick crash — the remaining shard keeps sweeping.
- `lastSweepError { kind, message, at, consecutiveCount }` written through the existing atomic state path, cleared on the next successful sweep, bounds state growth: repeated failures bump a counter rather than appending an unbounded log.
- Surfacing per-repo error counts in the tick envelope gives the dashboard a "repo went dark" signal without any new transport.
