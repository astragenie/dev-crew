## Lessons

- GitHub Actions comment-body injection must always use `$GITHUB_EVENT_PATH` + `jq` rather than `${{ github.event.comment.body }}` expression interpolation — the latter is the canonical prompt-injection vector per GH Actions security hardening guide.
- GITHUB_OUTPUT multi-line values must use heredoc delimiter pattern (`key<<EOF_TAG ... EOF_TAG`) — echo `key=$value` truncates on newlines and enables step-output injection when value is user-supplied.
