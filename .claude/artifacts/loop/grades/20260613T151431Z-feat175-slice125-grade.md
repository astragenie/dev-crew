## Lessons

- Non-null assertions on regex match groups require explicit index access (`match[1]!`) — TypeScript strict mode catches these cleanly at tsc time.
- Cyclomatic complexity of ≥21 in a single function is a design smell; extracting 4 single-responsibility helpers brought it under the 15-cap without losing readability.
- Pre-checking node-cap before adding edges (`willAdd` guard) is cleaner than post-hoc truncation; avoids off-by-one and keeps Mermaid output deterministic.
