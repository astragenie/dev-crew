## Lessons

- Prepending a pre-flight instruction block to the PM dispatch keeps the PM agent contract pure. PM is still "read FEAT body, return scores" — but now reads ALSO the prepended block which adds the AC-clarity gate. Zero agent edits, just a slash-command-level prefix.
- Naming matters: `/loop:retriage` reads clearly as "do triage but with the rework loop". `/loop:triage2` would have been confusing. Caller saved us the cycle.
- 7-step gate documented inline in the slash command (not in a separate skill) so the PM dispatch can read the whole flow in one prompt block. Skill split would have forced PM to invoke another Skill mid-flow — extra dispatch overhead.

## Surprises

- The base PM agent already had hooks to dispatch spec-writer in `agents/pm.md:62` + `:161`. The retriage flow just formalizes that into a mandatory pre-flight + adds the wait-and-re-read step. So the operational pattern was already partially documented, just not enforced.

## Followups

- Measure cost vs. quality: run a batch of pending FEATs through both `/loop:triage` and `/loop:retriage`, compare composite scores. If quality improvement justifies the 2× cost, flip `/loop:intake` Phase 1 to call `/loop:retriage` by default.
- Add a `--dry-run` flag that reports which FEATs would have triggered the pre-flight without actually dispatching spec-writer. Useful for cost estimation.
- Consider extending the same prefix-pattern to `/loop:backlog-enrich`: an opt-in higher-quality variant that dispatches loop:researcher to verify tag classification.

## What went well

- 5 tests pinning the contract by intent (regex anchors on AC-clarity, spec-writer, Given-When-Then, needs-review, /loop:triage back-compat). Durable across copy-edits.
- CLAUDE.md + CHANGELOG positioned the new command as opt-in higher-quality, not a /loop:triage replacement. Operators choose per batch.
- Zero source-code changes — pure slash-command + docs + tests. Lowest-risk surface for a workflow change.

## What went wrong

- Initial slice proposal modified agents/pm.md directly. Operator caught it ("add it as a separate command like retriage") — saved a more invasive change. Future: when proposing agent-contract changes, also propose the slash-command-prefix alternative.

## What I would do differently next time

- Default to slash-command-prefix patterns for opt-in agent-behavior tweaks. Modifying the agent itself is one-way and global.
