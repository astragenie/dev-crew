## Lessons

- A builder's pre-apply STOP on a dry-run diff (kb's 130-line body vanishing) caught a latent inter-span deletion bug that 18 prior green migrations never exercised — marker spans happened to be adjacent everywhere else. Estate diversity, not test count, exposed it.
- Installer appends new marker blocks at file END while legacy blocks sit at file TOP — any multi-span collapse tool must treat the gap between them as protected content, never as span-adjacent whitespace.

## Decisions
