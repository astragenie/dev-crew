## Key Lesson

**Signature changes require exhaustive call-site grep before marking done.**

When `AugmentArgs` gains a required field (`repoRoot`), ALL callers must be updated. Early submission missed the dry-run branch (`dispatch.mts:102`). The lesson: before declaring a function signature change complete, grep the repo for the function name and manually inspect every call site, including test fixtures and feature branches.

This was caught by Reviewer B (rejection on tsc gate), then fixed in commit 2996cff. The fix is minimal (1 line added to dry-run call site) but the meta-lesson is valuable for future refactors.
