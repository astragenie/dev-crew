## Lessons

- **Slash flows beat marker queues for inline orchestration.** v0.8.5 proved the slash-flow pattern works for `/loop:backlog-enrich`; SLICE-50 generalized that to all four affected CLI sites. Marker-queue scaffolding shipped in DEC-004 was an over-engineered prediction of demand that never materialized.
- **Architect's plan-preflight artifact is high-leverage even for "mechanical" removal slices.** 16 numbered steps + 4 OQs + 4 risks made builder execution low-variance. Without the OQ on DEC location alone, builder would have written to `docs/decisions/` (sparse copy) instead of the live `.claude/artifacts/loop/decisions/` store.
- **Backward-compat flag-as-no-op pattern (--no-research/--no-architect/--no-doc-writer) works well.** Cheap to implement, prevents CI breakage, telemetry visible via auto-dispatch.jsonl skipReason field — can be removed in a follow-up after a deprecation window.

## Followups

- **classifySlice in feature-lifecycle.mts** still calls dispatchAgent (deferred per OQ-4). File a follow-up FEAT once telemetry confirms no production callers depend on its marker-writing behavior. Same refusal-vs-slash treatment applies.
- **`--no-*` flag deprecation window.** Once auto-dispatch.jsonl shows zero use of `--no-research/--no-architect/--no-doc-writer` for ~2 weeks, remove the flags entirely.
- **skipReason naming normalization.** Standardize to `cli-refusal-<surface>` form across all four sites for cleaner telemetry queries.

## What went well

- Plan-preflight architect dispatch ahead of builder produced a concrete 16-step execution plan that builder followed without scope creep
- AutoMode HARD RULE landed mid-slice, immediately exercised on the same slice — no per-step approval interrupts; full builder→reviewer→validator→doc-writer chain ran with one user input ("y" to FF merge of branch ceremony, then full autonomy)
- Reviewer + Validator gates ran sequentially per orchestrate-slice ladder; both PASS without rework loops
- v0.10.0 release ceremony folded into the same slice — no separate release commit

## What went wrong

- Builder's intermediate diagnostics showed broken state mid-execution (architectOptOut, dispatchArchitectForSpec, DispatchFn unresolved references). These resolved by the time the agent returned, but the noise consumed reviewer cycles to confirm clean final state.
- One lint warning (`sanitizeResearcherBody` unused) slipped past builder; lead had to clean up post-builder before reviewer dispatch.

## What I would do differently next time

- Have the builder return its handoff WITH a final `npm run build && npm run lint` exit summary so the lead can short-circuit the post-cleanup pass when both are green.
- Add a builder-side gate that fails if any newly-declared TypeScript identifier becomes unused mid-edit (a removal slice is a high-risk shape for this).
