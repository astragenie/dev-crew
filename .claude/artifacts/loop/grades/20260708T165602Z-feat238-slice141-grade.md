## Lessons

- A top-level static import of an optional peer dep resolves at module LOAD, before any runtime enabled-gate can run — so gate optional-dependency imports dynamically inside the gated block, never at module top.

## Decisions

### DEC-073: Dynamic-gate optional-dependency imports on dispatch-surface modules

**Rationale**: memory-context.mts is imported by post-builder-fanout and wave dispatch; a static optional-dep import there crashes every importer at load in repos lacking the package. Matching grade-writer/learnings' gated await import keeps one convention across the memory surface.

**Consequences**:
- Optional peer deps (astramem-client) never break module load; resolution failures degrade to fail-silent recall skips.

## Surprises

- Only the value import crashed; the sibling `import type { RecallHit }` is erased at compile time and never triggered runtime resolution.

## Followups

- True package-absence cannot be simulated with the package installed in this repo; the regression test asserts the disabled-memory gate short-circuits before any recall instead.
