## Lessons

- Sync existsSync + readdirSync keeps buildDispatchInstruction sync. No async ripple through walker-gates / start-slice. Cost: one synchronous filesystem call per dispatch building — negligible vs. agent dispatch overhead.
- Prepending the pre-flight string + separator `\n---\n\n` to the existing dispatch instruction is the lowest-impact wiring. Builder/parallel branches don't know about pre-flight; they just emit their normal output and the pre-flight wraps it.
- Test the precedence explicitly: pre-flight precedes PARALLEL DISPATCH header for fullstack slices. Without that test, a future refactor could swap order and break the architect-runs-first guarantee.
