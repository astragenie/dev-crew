## Key lesson

When adding a required field to a shared type, grep all call sites before declaring done.

This FEAT added `risk:` to slice frontmatter (required field). The injection point is `buildSliceContent` at line 129. That function is called from two code paths:
1. Direct call at `feature-lifecycle.mts` line 40 (within `generateSlicesFromFeature`) ✓
2. Indirect call at `feature-lifecycle.mts` line 145 (within `generateSlicesFromClassify`) ✓

Both paths correctly pass feature frontmatter down the call stack. A miss on either path would have caused `risk: undefined` in the generated slice, failing validation at CI time. The builder caught this by grepping `buildSliceContent` and tracing both callers. Recommend formalizing this as a pre-commit check: `require risk: in slice frontmatter` validation in YAML parser or CI gate.
