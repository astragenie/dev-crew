## Lessons

- FEAT promotion + slice scaffolding doesn't check whether the implementation is already on main. When a FEAT lingers in triaged across a release that ships its code, the loop will dispatch a builder that finds nothing to do. Cheap fix: `/loop:slice-from-feature` could grep for FEAT-NNN in `git log` and warn if commits already reference it.
- Builder artifact correctly reported "pre-committed work" — initial parent-loop reaction was to call this a lie. The check is `git merge-base --is-ancestor <sha> HEAD`, not `git log -n 10`. Default `git log` truncation masked the truth.
- Specialist-pause recurred twice on crew:lead in this slice. SOP says "fixup re-dispatch with hard output contract"; second dispatch added the contract and got further but still paused before fanout. Pattern is now persistent enough that the parent loop should bypass crew:lead entirely for sub-trivial bookkeeping slices and drive ceremony from main thread.

## Surprises

- FEAT-167 had 7 detailed AC at the FEAT level but only 3 ACs ended up in slice-a — most of FEAT-167's AC-3/4/5/6 were also pre-shipped in v0.40.0 (cost-regression observability). SLICE-99 scope shrinks accordingly.
- validate-manifests.mts exits 1 on a missing `.claude-plugin/marketplace.json` in the dev tree. Pre-existing, not a regression, but the slice AC required exit 0 — would have been a reviewer flag if reviewer had run.

## What went wrong

- Two crew:lead dispatches paused mid-orchestration before completing fanout. ~10 minutes burned on agent dispatch for work that the parent loop ended up doing inline.
- Initial parent-loop reaction to builder's pre-committed-work claim was to accuse the builder of lying — needed a second pass to verify commit ancestry properly.

## What I would do differently next time

- For bookkeeping-shaped slices (implementation pre-exists, only state advance needed), skip crew:lead entirely. Verify gates inline, write synthesis, close.
- At `/loop:slice-from-feature` time, dispatch a 30-second researcher to grep `git log --all -- <inferred-paths>` and `grep -r FEAT-NNN docs/`. Cheap pre-flight that catches pre-shipped FEATs before any builder dispatches.
