## Lessons

- Three modes of fallback (explicit median, explicit expected_usd, auto-flip via sample count) collapse into one branch decision in checkCostRegression. Defensive pattern: degrade to median whenever expected-formula inputs are missing.
- Adding optional effortPoints field to AggregateCostReport interface needed parser back-compat: missing field becomes null. Zero existing test fixtures broke.
- Sample-eligibility threshold (>= 3) lives as module constant EFFORT_POINTS_AUTOFLIP_THRESHOLD. Naming the constant ties the test to the source.

## Surprises

- checkCostRegression stayed under ESLint complexity cap without helper extraction. New branches are short (early-bind mode, ternary on threshold).

## Followups

- Cost-report writer (in hero-crew) needs to emit effort_points on slice-close. Without that, production stays in median mode regardless of config. File upstream-request.
- .claude/loop.json schema walker does not exist. validateCostRegressionConfig is ready to plug in once one is built.
- AC-2 backfill script: revisit if retrospective cost analytics ever needs effort_points on historic FEATs.
