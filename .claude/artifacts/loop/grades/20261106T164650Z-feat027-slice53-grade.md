## Lessons

- A policy that must read identically in five prompt files is only stable when a test asserts the exact sentence and the forbidden phrases; prose review alone let the five docs contradict each other for months. command-gate-policy.test.mts now pins the sentence and the three banned phrasings.
- Any new root -> crew/ import (here validation-gate.mts -> crew/scripts/lib/ci/consumer-ci.mjs) must be registered in validate-repo-boundary.mts ALLOWED_CROSS_IMPORTS in the same commit or gate 9 goes red; follow the existing phase-gate.mts entry rather than widening the rule.
- A wave open that rotates currentRun once per lane leaves every lane worktree carrying the LAST slice's run title; reviewer/validator gates still record correctly because the close gate reads status, not title, but cost attribution and run-brief paths point at the wrong slice. Open each lane's run inside its own worktree, or rotate after worktree creation.

## Decisions

### DEC-046: Validation-skip delegation is allowed only when consumer CI is detected, and is always recorded

**Rationale**: Five prompt files disagreed on whether LOW-risk slices need a verifier, and the config switch loop.validation.satisfiedByReview could waive validation in a repo with no CI at all. The skip now has one rule: one reviewer for LOW-risk slices, and the verifier is replaced by write-validation-result --decision skipped --skip-reason "delegated to CI: <workflow>" only when has-consumer-ci reports a push/pull_request-triggered workflow running the repo's test command; otherwise devcrew:verifier is dispatched. deriveValidationGate enforces the same condition at close.

**Consequences**:
- Validation is never silently waived: every skip is an artifact naming the CI workflow that covers it, and repos without CI always get a verifier.
- Consumer repos whose CI runs a test runner outside the known list (vitest/jest invoked directly, reordered args) are treated as no-CI and get a verifier dispatch they might not strictly need; extend KNOWN_TEST_COMMAND_PATTERNS when that shows up.
