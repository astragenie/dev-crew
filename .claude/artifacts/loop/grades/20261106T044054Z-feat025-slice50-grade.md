## Lessons

- A guard is only as real as the call path it sits on. FEAT-025's refusal logic landed in maybeEmitCostReport (interactive /crew:build) while this repo's own closes go through costSliceHandler via crew-bridge; both reviewer B and the verifier caught it independently from the same live evidence — zero of 57 cost reports carried run_id. Grep the callers before declaring a cross-cutting contract done.
- Silent pricing fallbacks hide model drift for months: every fable-5-1 session was billed at sonnet-4 rates until priceFor stopped prefix-matching. Exact-key-or-date-suffix matching plus an explicit unpriced_models list makes the gap visible instead of plausible.
- Root `bun run typecheck` covers tsconfig.json + tsconfig.test.json, not crew/tsconfig.json, and tsconfig.test.json runs strict:false where an awaited discriminated union does not narrow from a bare truthiness check under TS 7. Use `=== true` and say why, or the error reappears as a mystery in a different project.

## Decisions

### DEC-045: Cost-report honesty guards live in one shared helper applied to every write path

**Rationale**: Zero sessions scanned, a window wider than maxWindowHours without --allow-wide-window, or a duplicate run_id with identical totals each mean the report cannot be honest about what it measured. The three checks plus run_id resolution were extracted into cost-report-guard.mts's evaluateCostReportGuard and wired into both maybeEmitCostReport (interactive) and costSliceHandler (autonomous loop) rather than duplicated, because the first implementation shipped on only one of the two paths and nothing caught it until live evidence did.

**Consequences**:
- Slice cost reports now carry run_id and refuse rather than write a misleading artifact; aggregate writes stay ungated; pricing is exact-key-or-date-suffix with unpriced_models surfaced and a verdict of unknown when any model is unpriced; grade writes reject unfilled scaffold placeholder template tokens.

## Surprises

- The unfilled-title guard broke 48 tests across 10 grade fixtures because every fixture shipped the scaffold's the scaffold title placeholder token by design; the operator scaffold-then-fill-then-write flow was verified intact, so filling the fixtures was correct rather than a mask.

## Followups

- The unfilled-template guard scans the whole grade body, so prose that merely QUOTES the placeholder token is rejected as unfilled — it blocked this very grade until the words were rephrased. Narrow the check to the title line and score axes, or allow a fenced/backticked occurrence. Fold into FEAT-036 or file separately.
- Cursor-advance-on-refusal was fixed IN this slice (review B: the bug was unreachable until 58dcfb62 made the handler able to refuse, so the slice made it live) — the bridge now holds the cursor on any refusal. FEAT-036 keeps the broader hardening: explicit preserveCursor metadata on each reason, aggregate-mode gating, and operator recovery docs.
- Aggregate-mode cost writes are ungated by design (guard runs once, before the slice write); verifier confirmed the aggregate frontmatter carries no run_id. Narrow exposure, real gap.
- cost-report-dedup.mts (post-write, session-fingerprint, rewrites into shared_with) and cost-scan-cursor.mts (per-slice scan window) are orthogonal to the new run_id refusal; three overlapping mechanisms now guard cost honesty and should be consolidated or documented as a set.
- Stale eslint-disable comment and dead `fallback` key in pricing.json (reviewer A LOW); resolveRunId's fallback id could false-positive for two legacy runs sharing timestamps and usd.
- claude-sonnet-5 / claude-opus-5 / claude-haiku-4-5 rates are marked source: assumed (audit quotes 5.5-named rows); re-verify against published pricing before trusting cost trends.
