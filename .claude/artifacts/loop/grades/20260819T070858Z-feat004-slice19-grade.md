## What went well

The P3-exit ceremony smoke test actually executed the documented command invocations rather than trusting the green test suites, which is what caught the real problem: half the command surface documented invocations that 404'd despite every automated suite passing.

## What went wrong

Fixing the `/loop:` string broke 2 tests that hard-coded the old string — the same class of defect SLICE-14's token sweep hit, where a fix to user-facing text wasn't paired with a sweep of the test trees still asserting on the old string.

## What I would do differently next time
