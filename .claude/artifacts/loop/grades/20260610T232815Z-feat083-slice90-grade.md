## Decisions

### DEC-048: auto-dispatch.jsonl schema is strictly additive — both event and stepType discriminators co-exist for session-drift-override

**Rationale**: Pre-existing consumers (e.g. session-drift.test.mts) switch on `event`. New stepType discriminator gives a uniform field name across all entry kinds. Removing `event` would be a breaking change. Keep both; deprecate `event` only when no consumer reads it (separate FEAT).

**Consequences**:
- positive: zero risk of breaking existing readers; clean forward-migration path
- positive: stepType becomes the canonical discriminator for new readers (FEAT-165, FEAT-172)
- negative: redundant fields in JSONL until `event` is fully deprecated

**Affects files**: `src/scripts/lib/auto-walker.mts`, `src/scripts/lib/auto-dispatch.mts`, `docs/halt-badges.md`
