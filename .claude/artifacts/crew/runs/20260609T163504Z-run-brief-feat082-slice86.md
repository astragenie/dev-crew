- Created: 2026-06-09T16:35:04.909Z
- Goal: Add glob-scoped rule auto-attachment to the loop installer. Users declare rule files (Markdown) with `globs:` frontmatter in a configurable `rulesDir`. When `buildTokens` runs, it reads all rule files, filters to those whose globs overlap with the current slice's `in_scope_globs`, and renders matching rule bodies into a `{{rulesBlock}}` template token injected into MASTER_PROMPT.
- Mode: autonomous
- Pace: unattended
- Owner: loop
- Status: active
- Summary: -

  - `alwaysApply`
  - `description`)
